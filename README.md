# Thrive-Africa-AdMLAI-Group-5-Assignments
Advanced Machine Learning & AI Project

#Introduction:

This repository contains Group 5 assignments for the Advanced Machine Learning and Artificial Intelligence course at Thrive Africa (March 2026 Cohort)
The project focuses on applying modern machine learning techniques to solve real-world problems using Python and industry-standard libraries.

#Objectives: 

Implementing and evaluating advanced machine learning models
Applying data preprocessing and feature engineering techniques
Comparing model performance using appropriate metrics
Interpreting and communicating results effectively
